# Componentes e atribuição

- **Planck 1.4.2**: [repositório oficial](https://github.com/piqnt/planck.js), biblioteca de física sob MIT. Código em `vendor/planck.min.js`; texto de licença em `vendor/PLANCK-LICENSE.txt`.
- **Jost**: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/jost), SIL Open Font License 1.1. Arquivos locais em `assets`; licença em `assets/JOST-LICENSE.txt`. É uma fonte substituta nesta reconstrução.
- **Mapas importados**: nomes, autores e IDs publicados no serviço do Bonk.io são atribuídos em `MAPAS.md` e nos metadados dos mapas. Não se atribui a licença MIT desses componentes aos mapas ou aos assets do Bonk.io.
- **HTML, CSS, simulação, interface, editor, skins geométricas, sons sintetizados e arenas `local-*`** foram escritos para este projeto. Bundles originais do Bonk.io, decodificadores usados na pesquisa e recursos proprietários obtidos para inspeção não são distribuídos neste pacote.

Bonk.io é o jogo de referência. Esta edição local é um projeto independente, sem conexão com os servidores do jogo original.
